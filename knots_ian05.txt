Ian's new knots: by Ian J Norris

trying to understand too much
is attachment.
attachment
is trying to understand too much.

a dream becomes attachment
if you try to understand it.
there is always more to understand
in a dream.
if you try to understand,
a dream is attachment.
more to understand,
always more,
because there is always more
to understand.

there is always more
because there is always less.
if you try to understand,
it is attachment.
attachment is less
if you don’t want to know.

i don’t want to know
if i can never know.
we don’t want to know
if we can never know.
they don’t want to know
if they can never know.
and none of us knows
whether not knowing
is freedom
or just another way
of holding on.
