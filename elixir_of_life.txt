What This Program Does:
Core Features:

Nigredo: Breaking down the pattern, facing what's heavy
Albedo: Purification, clarity, distinguishing truth
Citrinitas: Integration, bringing divided parts together
Rubedo: Completion, stability, the gold state
Session Persistence — Saves every session so you can:

Track the entire journey
Return and continue when the problem evolves
Watch the transformation unfold over time
Script Evolution — When you return with an update:

Acknowledges growth already made
Recognizes the evolved problem
Generates the next phase of the work
Builds naturally on previous scripts
Multiple Session Management — Handle different clients/problems simultaneously
